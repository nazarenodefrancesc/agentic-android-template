# v0.1 Static Validation Report

Date: 2026-08-26

## Executed successfully in packaging environment

- repository structure validation (`scripts/repo-check.sh`);
- Bash syntax validation for all shell entrypoints;
- Python bytecode compilation of `scripts/task.py`;
- task metadata validation with an empty golden-template backlog;
- fresh-app derivation smoke test using:
  - app name: `Sample Calculator`;
  - package: `com.example.samplecalc`;
  - fresh independent `.git` initialization;
- post-derivation repository validation;
- package/path rewrite validation, including diagnostics and tests;
- stale template package/name scan;
- deterministic task-routing smoke test with dependency ordering and status transitions;
- Git repository integrity and tracked-secret checks.

## Defects caught during validation

1. A source package initially named `build` collided with the standard `**/build/` Git ignore rule. It was renamed to `diagnostics`.
2. Broad tar exclusion patterns could also have removed legitimate source directories named `build`. Derivation now uses `git archive HEAD`, which copies only committed golden-template state and naturally excludes caches, secrets and `.git`.
3. Gradle 9 removed `Project.exec`; build provenance now uses configuration-cache-compatible `providers.exec`.
4. First-time Gradle-wrapper creation was decoupled from Android project configuration by generating the wrapper inside a temporary plain Gradle project.

## Not executable in packaging environment

The packaging environment has no Android SDK, no preinstalled Gradle and no external dependency network access. Therefore these gates are intentionally unverified here:

- Gradle dependency resolution;
- Kotlin/Compose compilation;
- Android lint execution;
- unit tests executed by Gradle;
- managed-device/emulator tests;
- QA APK assembly/install/signature update behavior.

These are first-class gates for the target build server and the first derived sample app. Do not treat them as implicitly passing.
